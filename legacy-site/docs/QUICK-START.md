## 🔧 Customization (Optional)

Want to adjust the imagery? Look for these in the CSS:

### Adjust Star Opacity
```css
Search for: opacity: 0.08
Change to: opacity: 0.15 (more visible)
Or: opacity: 0.05 (more subtle)
```

### Change Animation Speed
```css
Search for: animation: floatGeometry 20s
Change to: 30s (slower) or 10s (faster)
```

### Modify Colors
```css
Search for: #d4a853 (gold)
Or: #6b4c9a (purple)
Replace with your preferred colors
```
